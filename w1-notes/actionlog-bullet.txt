- **The action log keeps no values.** For the ready session, each pane's proxy records what it forwarded to the app: the method, the path, the status, the time it took and the bytes it sent back. It never records a header, a cookie, a body or a query value: a query keeps its keys, and a path segment that looks like a value (a token, an email address, a number of nine digits or more) shows only what kind it was. Requests a guard refuses are only counted, by reason, so another page can't write entries. The harness adds a mark for each click, submit, change or Enter a pane reports: the pane and the kind of action, never the element or what was typed. A mark comes from that pane's own bridge, which PR code can drive, so it says which pane reported it. The log lives in memory, behind the capability like the rest of the API, and goes with its session. Nothing of it reaches the event stream, the conductor's log or GitHub ([HTTP API](#http-api-harness-port)).
